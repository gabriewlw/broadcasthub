# Channel logos

18 original PNG files from [tv-logo/tv-logos](https://github.com/tv-logo/tv-logos/tree/d32e347bb7c4c640dceec23957802ad9182f58a6), retrieved 2026-10-08. Logo storage is restricted to the 22 Galaxy 31 entries supplied by the user from [LyngSat](https://www.lyngsat.com/Galaxy-31.html). 20 entries have logos; Rai Italia Nord America and the CruiseSat test card display text only. The ESPN and ESPN 2 Caribbean feeds share their respective US network wordmark files to avoid duplicate storage.

Files are named by the IPTV-org channel ID. Individual original source URLs and the supplied lineup are recorded in `../satellite-channels.json`. Images are bundled unchanged; browser CSS displays them immediately after the channel name at its font height. No logos outside this lineup are stored or fetched automatically. The broader name reference remains available for Satellite source suggestions.

The catalog metadata is CC0; channel logos retain their respective brand ownership. See `docs/satellite-channel-reference.md` for the reference list and channels without bundled images.
