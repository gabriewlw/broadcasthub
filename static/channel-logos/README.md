# Channel logos

Original PNG files from [tv-logo/tv-logos](https://github.com/tv-logo/tv-logos/tree/d32e347bb7c4c640dceec23957802ad9182f58a6), retrieved 2026-10-08. Files are named by the IPTV-org channel ID. Individual original source URLs are recorded in `../satellite-channels.json`. Images are bundled unchanged; browser CSS displays them at the channel name’s font height.

The catalog metadata is CC0; channel logos retain their respective brand ownership. See `docs/satellite-channel-reference.md` for the reference list and channels without bundled images.
